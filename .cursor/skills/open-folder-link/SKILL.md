# フォルダを開くリンク

最後に成果物をユーザーへ出すときは、フルパスに加えてフォルダを開くリンクを必ず付ける。
最後の報告でファイルやフォルダのパスを示すときも同じ。

## 形式

- ファイルはフルパスをバッククォートで書く。区切りは `/`。
- リンク先はファイルではなく、そのファイルが入っているフォルダ。
- 表示文字は「フォルダを開く」。
- URI は `file:///` のあとにドライブレターと `/` 区切りのパス。スペースは `%20`。
- 同じフォルダのファイルが続くときは、フォルダリンクは1つでよい。
- フォルダだけを示すときは、そのフォルダをリンク先にする。

## 例

`D:/BRStudio/Projects/Human3Dmodel/30_gen/3d/woman_20s_office_head_60k_20261020/woman_20s_office_head_60k.glb`
